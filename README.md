# 데빌 서바이버 2 NDS 한국어 패치 v1.0

배포일: 2026-10-24
대상: Devil Survivor 2 일본판

배포 ZIP에는 원본 ROM이나 패치 완료 ROM이 포함되지 않습니다. 아래 일본판 NDS 원본과 정식 한국어판 3DS 『데빌 서바이버 2 브레이크 레코드』의 복호화된 파일이 필요합니다. 패처는 사용자가 제공한 3DS 파일에서 한국어 데이터를 읽어 NDS에 적용합니다.

3DS 대상 제품 코드는 `CTR-P-ADXK`입니다. 위 3DS 해시는 검증에 사용한 `.3ds` 파일 기준입니다. 패처는 컨테이너 전체 해시 대신 내부 게임 데이터와 프로그램의 해시를 확인합니다. 파일 선택 창에서 `.3ds`, `.cci`, `.cxi`, `.cia`를 받지만, 이번 배포의 전체 적용 검사는 위 `.3ds`로 진행했습니다. 복호화 기능이나 암호 키는 포함하지 않습니다.

## 적용 방법

1. ZIP을 풀고 `DevilSurvivor2-KO-v1.0-terms-fixed.exe`를 실행합니다.
2. **일본판 NDS**에서 수정하지 않은 일본판 원본 `.nds`를 선택합니다.
3. **3DS 한국어판**에서 복호화된 한국어판 『브레이크 레코드』 파일을 선택합니다.
4. **결과 저장 위치**에 새 `.nds` 파일 이름을 지정합니다.
5. **패치 시작**을 누르고 완료 메시지가 나올 때까지 기다립니다.

Windows 64비트용입니다. 패치 과정은 오프라인으로 동작합니다. 본문 글꼴을 만들 때 Windows에 설치된 굴림(`gulim.ttc`)을 읽으므로 한국어 글꼴이 필요합니다. 글꼴이 없다는 안내가 나오면 Windows의 한국어 글꼴 기능을 설치한 뒤 다시 실행하세요. 글꼴 생성 결과가 v1.0 기준과 다를 때도 저장을 중단합니다.
